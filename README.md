# Python Subscriber Tracker

A beginner-friendly desktop application built with Python and Tkinter to track and manage subscriber counts.

This project was created to practice Python fundamentals, GUI development, user input validation, and event-driven programming.

## Features

- Display the current subscriber count.
- Update the subscriber count by entering a custom number.
- Increase the subscriber count using a button.
- Reset the subscriber count to zero.
- Validate user input to prevent negative numbers and invalid entries.
- Display helpful error messages for invalid input.

## Technologies Used

- **Python 3** — Core programming language.
- **Tkinter** — Python's standard GUI library, used to build the desktop interface.
- **Git** — Version control for tracking project changes.
- **GitHub** — Hosting and sharing the project repository.

## How to Run the Application

1. Install Python 3 on your computer.
2. Clone this repository using Git:

   ```bash
   git clone https://github.com/ariley-labs/python-subscriber-tracker.git
   ```

3. Open the project folder in VS Code or another code editor.
4. Run the application from your terminal:

   ```bash
   python widget_window.py
   ```
